# Worked Example Two: When Neither Target Should Actually Get a Message

The first [example](../example/) tests a weak generic hook against a strong specific one, for a target that genuinely fits. This one tests two different stop conditions: a target with no actual verifiable signal to anchor to, and a target who looks like an easy fit by title but genuinely is not, once checked.

- [inputs.md](inputs.md): two more fictional targets for someone seeking a documentary filmmaking mentor
- [output.md](output.md): the response, correctly declining to draft a message for either
- [review.md](review.md): whether both refusals were actually justified, not just cautious by default
